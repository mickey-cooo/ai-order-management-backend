# Project Rules

## Git

### Commit
- Use `git-cz` (already installed) to commit. Commit message carries emoji.
- Format example: `fix(emoji): example commit`
- No Claude/AI attribution in commit messages.

### Push
- Never push without asking first.
- Ask user before every push. Push only after user replies "go ahead".
- Approval applies to that one push only. Ask again next time.
